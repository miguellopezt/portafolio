Sobre mí

Ingeniero en formación en Tecnologías de la Información Geoespacial con un perfil técnico amplio y orientado a producto. Mi trabajo abarca el ciclo de vida completo del dato: desde la ingesta automatizada mediante pipelines ETL hasta su explotación en modelos predictivos, sistemas de detección de objetos y productos web con IA integrada, desplegados en producción sobre infraestructura cloud.

Combino disciplinas que habitualmente viven separadas: ingeniería de datos geoespacial, Machine Learning clásico (XGBoost, modelos hedónicos), Deep Learning aplicado a visión por computador (YOLO), arquitecturas Fullstack asíncronas y análisis territorial avanzado con GIS. Cada proyecto que desarrollo es una oportunidad para profundizar en un área nueva sin abandonar el rigor en las anteriores.

Mi dominio técnico se basa en estas áreas:

Ingeniería de datos & Cloud: Diseño y despliegue de pipelines ETL automatizados en Python para la extracción, transformación y unificación de fuentes masivas en tiempo real. Despliegue y orquestación de servicios en infraestructuras de Oracle Cloud, con gestión de proxies inversos (Nginx) y configuración de workers para carga concurrente.

Machine Learning & Modelos Predictivos: Implementación de modelos hedónicos y de gradient boosting (XGBoost) para regresión de variables complejas, con ingeniería de features geoespaciales como núcleo diferencial. Desarrollo Web & Integración de IA: Arquitecturas Fullstack con backend asíncrono en FastAPI (Python) y frontend interactivo en React (Vite), con integración de LLMs mediante Server-Sent Events para asesoramiento en tiempo real. Renderizado cartográfico avanzado con MapLibre GL JS y Leaflet.

GIS & PostGIS: Dominio avanzado de ArcGIS Pro, QGIS y PostGIS, apoyado en el stack geoespacial de Python (GeoPandas, Shapely, Rasterio), para el desarrollo de análisis territoriales complejos y la generación de capas espaciales enriquecidas.

Teledetección & Análisis Espectral: Procesamiento de imágenes satelitales, modelado predictivo de índices espectrales (NDVI) y estudio de patrones de cobertura del suelo aplicados a agricultura de precisión y análisis ambiental.

Proyectos Destacados

GradientEstate — Ecosistema PropTech
Data Engineering · GIS · ML · IA Generativa · Fullstack · Cloud

Ecosistema PropTech end-to-end centrado en el municipio de Madrid que automatiza el análisis y la valoración inmobiliaria mediante inteligencia de datos geoespaciales, modelos predictivos y asesoramiento por IA en tiempo real.


El núcleo del sistema son los pipelines ETL que cruzan más de 10 datasets con componente geográfica para generar capas espaciales propias: contexto socioeconómico, accesibilidad urbana, indicadores ambientales y momentum de mercado por zona. Estas geometrías enriquecidas alimentan un modelo XGBoost para regresión de precios, con variables precomputadas para hacer viable la inferencia en tiempo real. El sistema genera mapas de calor y capas temáticas que traducen esa densidad de información en visualizaciones accionables.


El backend asíncrono en FastAPI orquesta la concurrencia de peticiones de inferencia sin bloqueo. Un asesor analítico basado en LLM se integra mediante Server-Sent Events sobre motores de inferencia de latencia ultrabaja. El frontend está construido en React (Vite) con renderizado cartográfico mediante MapLibre GL JS, consumiendo teselas vectoriales alojadas en ArcGIS Online.


Desplegado en producción sobre Oracle Cloud Infrastructure, bajo dominio propio, con Nginx como proxy inverso y workers Uvicorn afinados para sostener carga mixta de inferencia ML y peticiones web concurrentes.

Sistema de Calidad del Aire: Visor Web Multianalítico (En Proceso)
ETL & Análisis & Fullstack & IA & Cloud

Sistema que integra Pipelines ETL en Python que recopilan y unifican datos en tiempo real de múltiples fuentes (CC.AA. y MITECO) para el cálculo y visualización del Índice de Calidad del Aire (AQI) en España.


El backend del sistema, orquestado por FastAPI, se encarga de la generación de mapas de calor, así como de la limpieza automatizada de los últimos datos. Además, entrenará modelos de Redes Neuronales (LSTM) aplicables, permitiendo realizar predicciones precisas del AQI, combinándose con variables climáticas en tiempo real.


El frontend consiste en un visor interactivo desarrollado con React + Vite y Leaflet.


El sistema se encuentra desplegado en una instancia de Oracle Cloud, garantizando alta disponibilidad para la implementación y orquestación de servicios, facilitando el acceso web mediante una URL bajo un DNS público.
